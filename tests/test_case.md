# Dokumentasi Pengujian Program

Nama Proyek: Program Analisis Nilai Matematika Siswa Berbasis Python

## Hasil Pengujian

| No | Skenario Pengujian | Hasil yang Diharapkan | Hasil |
|---|---|---|---|
| 1 | Nilai tepat 75 | Status Lulus | Berhasil |
| 2 | Nilai 105 | Ditolak dan diminta input ulang | Berhasil |
| 3 | Input huruf abc | Ditolak dan diminta input ulang | Berhasil |
| 4 | Jumlah siswa 0 | Ditolak dan diminta input ulang | Berhasil |
| 5 | Nilai 0 | Diterima, status Belum Lulus | Berhasil |

## Kesimpulan

Berdasarkan lima pengujian yang dilakukan, program dapat menerima
input yang valid, menolak input yang tidak valid, menghitung
statistik nilai, dan menentukan status kelulusan siswa dengan benar.
